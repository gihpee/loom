# looma-connect

Локальный порт до Ray-кластера, который живёт на машине за NAT.

```bash
uv tool install looma-connect
looma-connect 201.34.135.177:8000 group-cf6421224f --token <ваш токен>
# слушаю 127.0.0.1:10001 → group-cf6421224f
#     ray.init("ray://127.0.0.1:10001")
```

Дальше вы пишете обычный код у себя:

```python
import ray

ray.init("ray://127.0.0.1:10001")

@ray.remote
def square(n):
    return n * n

print(sum(ray.get([square.remote(i) for i in range(100)])))
```

## Зачем это нужно

У машины с картой нет входящих портов и не будет: это домашний компьютер за
роутером, который её владелец не настраивает. Наружу смотрит только
оркестратор, и он же доносит байты до узла по соединению, которое **узел
открыл сам**.

Поэтому публичного адреса у кластера не существует, и вместо него — локальный
порт у вас.

## Почему это отдельная программа

Она ставится тому, у кого нет ни репозитория Looma, ни Docker, ни доступа к
узлам. Поэтому здесь **ни одного импорта из проекта** и ровно одна
зависимость. Общий с Looma только протокол, описанный ниже.

Отдельность проверяется тестом (`tests/test_isolation.py`), а не намерением:
через полгода кто-нибудь переиспользует отсюда одну функцию, и утилита
перестанет ставиться.

## Протокол

```
GET wss://<оркестратор>/connect/<группа>
X-Looma-Admin-Token: <токен>
```

Одно соединение WebSocket на одно TCP-соединение — мультиплексировать незачем,
Ray Client открывает их единицы. Байты идут двоичными кадрами как есть,
никакой своей рамки: WebSocket уже даёт границы сообщений.

Закрытие с любой стороны закрывает TCP целиком; полузакрытых состояний нет.

Токен едет **заголовком**, а не параметром адреса: параметры оседают в логах
прокси и в истории команд, а этот токен даёт право исполнять код на чужой
машине.

## Где взять адрес и имя группы

На вкладке **Ray** в панели, на карточке работающего кластера — там же готовая
команда с кнопкой «скопировать». Токен в неё не подставляется намеренно: он
даёт право исполнять код на чужих машинах, а такая команда попадает и в
скриншот, и в переписку.

Токен можно не писать каждый раз:

```bash
export LOOMA_TOKEN=...
looma-connect 201.34.135.177:8080 group-cf6421224f
```

## Что должно быть на той стороне

- кластер поднят с `ray[client]` — иначе клиентского входа у него нет
  (панель ставит его сама);
- если панель за nginx, у `/connect/` должен быть проброшен upgrade
  WebSocket — в поставляемом конфиге он есть.
